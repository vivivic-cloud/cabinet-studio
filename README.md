# 캐비닛 설계실

치수만 넣으면 판재 수납장을 3D로 확인하고, 삼면도(정면도·측면 단면도·평면 단면도)와 부품표를 DXF/SVG로 내보내는 웹 기반 가구 설계 도구.

- 설치 없음 — 브라우저에서 바로 실행 (three.js, JSZip은 CDN)
- 파라미터: 폭·깊이·높이, 판재 두께, 뒷판 두께, 상판 결합 방식, 선반 단수, 걸레받이, 문짝
- 3D 뷰: 회전·확대, 분해도
- DXF (R12, 레이어 분리, 한글 텍스트) / SVG 내보내기
- 부품표: 결 방향 기준 재단 치수, 두께별 소요 면적

`index.html` 하나로 동작합니다.
